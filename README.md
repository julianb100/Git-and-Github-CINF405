Project Description

Student Task Management is a Python application designed to help college students organize their academic assignments, exam dates, outside homework assignments and manage their workload more effectively. Students often have multiple assignments, projects, and deadlines to keep track of, and this application provides a central place to record and review their academic responsibilities.

The application is planned to allow users to add, view, edit, and delete assignments, date alerts, assign priority levels, set due dates, and mark tasks as completed. It will also provide a way to review upcoming deadlines and save assignment information locally so that tasks remain available between program sessions.

This project will be developed through the semester as part of the CINF 405 Semester Design Project.

Technologies and Tools

- Programming Language: Python
- Data Structures: Lists and dictionaries
- Data Storage: Local file handling
- Development Tools: Python code 
- Version Control: Git
- Repository Hosting: GitHub

Planned Features

- Add new assignments with titles, descriptions, and due dates.
- Assign priority levels to tasks.
- View and edit existing assignments.
- Delete assignments that are no longer needed.
- Mark assignments as completed.
- Review upcoming deadlines.
- Save and load assignment data between sessions.
